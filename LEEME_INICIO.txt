ERP COMERCIAL PERU - GUIA RAPIDA (VERSION MEJORADA)

1. Extrae todo el ZIP.
2. Instala Node.js 24 LTS o posterior.
3. Abre la carpeta ERP-Comercial-Peru en VS Code.
4. En la terminal escribe:
     npm ci
     npm run dev
5. Abre http://localhost:5173

En Windows puedes hacer doble clic en INICIAR_ERP.bat.

ADMINISTRADOR DEL AULA
Correo: admin@enterprisecloud.demo

Al entrar al aula por primera vez se cargan datos comerciales de
practica automaticamente: 30 clientes, 40 productos, almacenes,
cotizaciones, pedidos, ventas, cobros y compras.

Si tu navegador tenia una instalacion antigua sin datos, ingresa a
Datos maestros y selecciona "Restaurar escenario de aula".
Esta accion pregunta antes de reemplazar los registros locales.

La pantalla Rutas permite elegir A, B, repartidor, monitor y el
pedido relacionado. Las rutas personalizadas de prueba se simulan en
linea recta; el GPS real utiliza las posiciones del dispositivo.

Para generar version compilada: npm run build y despues npm start.
Para pruebas automatizadas: npm test.

Consulta MEJORAS_REALIZADAS.md para novedades, guion y limitaciones.
