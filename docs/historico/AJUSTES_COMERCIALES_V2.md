# Ajustes de interfaz — flujo comercial

- Sidebar: «Flujo comercial», sin números en las entradas; la guía de proceso dentro de las vistas mantiene su numeración.
- Cotizaciones, pedidos y ventas: nueva ficha contextual lateral para cliente, producto, almacén (en ventas) y total de líneas agregadas.
- Registros: botón «Ver detalle» para cotizaciones, pedidos, ventas, cobros y devoluciones. Presenta datos disponibles, relaciones y líneas de productos cuando corresponda.
- Botones: aprobación en verde discreto, conversión en azul, facturación en azul sólido y cancelación/anulación en rojo discreto.
- Se conservan modelos, persistencia, lógica existente y paginación.

La compilación completa requiere instalar dependencias (`npm install` y `npm run build`).
